# S1 Hub

S1 Hub is a Surgery Posting study companion built from the M1 Hub architecture. It contains the 57 Surgery topics supplied for this project, grouped by surgical specialty.

## Features
- Taught, Read and Revised tracking per topic
- Flagging and personal notes
- Revision centre with 1–3–7–14-day review rhythm
- Study streak and progress overview
- Search, specialty and status filters
- Dark and light themes
- JSON backup and restore
- Confirmed progress reset (preserves notes, theme and syllabus)
- Vercel Web Analytics integration

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

User data is stored locally under `s1hub-v1`, separate from M1 Hub.
